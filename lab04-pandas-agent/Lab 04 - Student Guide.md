## 🎯 Lab Objectives

The objective of this laboratory is to construct and operate an autonomous, code-generating data analyst agent. This agent interprets business questions in natural language, translates them dynamically into executable Python/Pandas operations, and delivers quantitative findings and dynamic statistical charts without requiring manual SQL queries or rigid analytical dashboards.

Upon completing this laboratory, you will be able to:
1. Configure a cognitive data analysis agent integrated within Google Colab powered by **Gemini Flash 3.8** (`gemini-3.8-flash`).
2. Implement autonomous data hygiene routines (`sanitizar_dados()`) to clean whitespace anomalies and string inconsistencies across raw records.
3. Formulate advanced natural language queries covering demographic segmentation, income dispersion, and socioeconomic correlations.
4. Audit the intermediate code layer generated by the LLM, identifying subtle analytical bugs or skewed filter logic.
5. Generate dynamic statistical visualizations (scatter plots, distributions, bar charts) rendered on-the-fly via executed Python syntax.

The raw US Census dataset contains leading whitespace in categorical strings (e.g. `' Female'` instead of `'Female'`). Execute the autonomous cleaning routine:
